# Contributing / 参与贡献

Please keep changes focused and run `zsh test.sh`, `zsh build.sh`, and `python3 scripts/check_public.py` before submitting a pull request. Use Swift 6+ on macOS; tests use the bundled Swift Testing framework. Add regression coverage for changes to diagnosis or log parsing. CI builds both Apple Silicon and Intel.

Public issues should include the app version, macOS version, the status light, and a **sanitized** one-sentence summary. Never attach authentication files, raw Codex logs, account identifiers, private prompts, full diagnostics, corporate proxy hostnames, or screenshots of actual usage without reviewing and redacting them. Prefer a minimal synthetic log line or screenshots generated by `--demo`.

To update screenshots, run `zsh scripts/screenshots.sh`. It uses the real UI with offline fixtures. Visually inspect both PNGs and verify the DEMO banner before staging them. Keep English and Chinese READMEs consistent. Do not add analytics or silently expand data collection.

---

请保持改动范围集中，提交 PR 前运行 `zsh test.sh`、`zsh build.sh` 和 `python3 scripts/check_public.py`。使用 macOS 上的 Swift 6+；诊断与日志解析变更应有回归测试。CI 构建 Apple Silicon 与 Intel 两种架构。

公开问题报告只需应用版本、macOS 版本、状态灯和**脱敏后**的一句话总结。不要直接附上认证文件、原始 Codex 日志、账号标识、私人提示词、完整诊断、公司代理域名或未经审核的真实额度截图。优先提供合成日志行或 `--demo` 截图。

更新截图时运行 `zsh scripts/screenshots.sh`，检查图片和 DEMO 提示后再暂存。请同步维护中英文 README，不添加分析上报或未经说明扩大数据收集。
